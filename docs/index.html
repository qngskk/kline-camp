训练规则

  1. 标的来自本地通达信日线，价格已做前复权（除权除息缺口被抹平，最新价不变）。
  2. 随机抽一只股票 + 一个随机日期，日期保证之前有 3 个月 K 线、之后至少还有整个操作窗口。
  3. 每一轮你只能看到「已揭示」的 K 线，决策不得使用未来数据。
  4. 买入 / 卖出 / 结束交易清仓，一律以次日开盘价成交；观望则直接进入下一日。
  5. 仓位 = 本次买入动用当前总资产的比例（满仓 / 1/2 / 1/3 / 1/4），按一手 100 股向下取整。
  6. 涨停开盘无法买入、跌停开盘无法卖出（主板 ±10%，创业板/科创板 ±20%）。
  7. 操作满 30 / 60 / 90 个交易日后自动结算，剩余持仓按最后一日收盘价折算。
  8. 已剔除现行 ST 股、上市不足 250 个交易日的次新股、北交所与 B 股。
